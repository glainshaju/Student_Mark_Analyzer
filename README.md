# 🎓 Student Marks Analyzer

A beginner-friendly C++ console application that analyzes student marks and generates a performance report.

This project was developed as part of my C++ learning journey to practice functions, arrays, loops, conditional statements and input validation.

## 🚀 Features

- Enter the number of students (1–100).
- Store student marks using arrays.
- Calculate total marks.
- Calculate average marks.
- Find the highest and lowest marks.
- Count passed and failed students.
- Repeat the analysis without restarting the program.
- Validate student count and marks.

## 🛠️ Technologies Used

- **Language:** C++
- **Concepts:** Functions, Arrays, Loops, Conditional Statements, User Input and Return Types.
- **Compiler:** GCC / G++

## 💻 How to Run

**1. Clone the repository**

```bash
git clone https://github.com/glainshaju/Student_Mark_Analyzer.git
```

**2. Open the project folder**

```bash
cd Student_Mark_Analyzer
```

**3. Compile the program**

```bash
g++ Project.cpp -o StudentAnalyzer
```

**4. Run the program**

Windows:

```bash
StudentAnalyzer.exe
```

Linux / macOS:

```bash
./StudentAnalyzer
```
